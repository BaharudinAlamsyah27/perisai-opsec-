# Foto Contoh Fiktif

Semua JPG pada direktori ini dibuat secara sintetis untuk demonstrasi PERISAI OPSEC; tidak memuat foto personel nyata.

- Set contoh analisis: `01_foto_bersih`, `02_gps_saja`, `03_papan_satuan_nrp`, `04_dokumen_rahasia`, dan `05_plat_nomor_sah`.
- Set pola hidup: `11` sampai `18`, dengan koordinat dan waktu EXIF buatan.
- Ukuran semua 13 JPG: kurang dari 2 MB (diukur dari file yang disertakan).
